# Deploy to Railway (Free & Easy)
# 1. Go to: https://railway.app
# 2. Sign up with GitHub
# 3. Click "New Project" → "Deploy from GitHub repo"
# 4. Connect your GitHub repo
# 5. Railway auto-detects Node.js and deploys!
# 6. Get your free URL (like: your-app.up.railway.app)

# Deploy to Render (Free & Simple)
# 1. Go to: https://render.com
# 2. Sign up (free)
# 3. Click "New" → "Web Service"
# 4. Connect your GitHub repo
# 5. Set build command: npm install
# 6. Set start command: node server-free.js
# 7. Deploy! Get free URL

# Deploy to Fly.io (Free & Powerful)
# 1. Install flyctl: https://fly.io/docs/getting-started/
# 2. Run: fly launch
# 3. Choose region, accept defaults
# 4. Run: fly deploy
# 5. Get free URL

# For Local Sharing (Advanced):
# 1. Find your local IP: ipconfig (Windows)
# 2. Share: http://YOUR_IP:3000
# 3. But friends need to be on same network OR port forward
